# Customer_behavior_analysis
End-to-End Customer Shopping Behavior Analysis using python, SQL and Power bi. Includes data cleaning, exploratory data analysis, SQL Queries and an interactive dashboard to uncover customer purchasing patterns and business insights 
🛍️ Customer Shopping Behavior Analysis

📌 Project Overview

This project focuses on analyzing customer shopping behavior to identify purchasing patterns, customer preferences, spending habits, and business insights.

The project follows an end-to-end data analytics workflow using Python, SQL Server, and Power BI.

The objective is to transform raw shopping data into meaningful insights that can help businesses understand their customers and make better data-driven decisions.

🛠️ Tools & Technologies

- Python: Data Cleaning, Data Manipulation, and Exploratory Data Analysis.
- Pandas: Data Processing and Analysis.
- Matplotlib: Data Visualization.
- Jupyter Notebook: Python Development Environment.
- Microsoft SQL Server: Data Storage, SQL Queries, and Business Analysis.
- Power BI: Interactive Dashboard and Data Visualization.

📂 Dataset Information

- Dataset: Customer Shopping Behavior
- Total Records: 3,900
- Total Columns: 18
- Format: CSV

The dataset contains information about:

- Customer ID
- Age and Gender
- Purchased Items
- Product Categories
- Purchase Amount
- Location
- Season
- Review Ratings
- Subscription Status
- Shipping Type
- Discounts and Promo Codes
- Previous Purchases

🔍 Project Workflow

1. Python – Data Cleaning & Exploratory Data Analysis

- Imported the dataset using Pandas.
- Inspected dataset structure and data types.
- Checked missing values and duplicates.
- Performed descriptive statistical analysis.
- Analyzed customer demographics and purchasing behavior.
- Explored category-wise and customer-wise patterns.
- Created visualizations using Matplotlib.

Notebook: "Customer_Shopping_Behavior_Analysis.ipynb"

2. SQL Server – Data Analysis

- Imported the cleaned dataset into Microsoft SQL Server.
- Performed business-oriented SQL queries.
- Analyzed customer purchasing patterns.
- Identified customer segments.
- Analyzed discount usage and purchase amounts.
- Evaluated product ratings and category performance.
- Analyzed revenue contribution across age groups.

3. Power BI – Interactive Dashboard

Created an interactive Customer Behavior Dashboard featuring:

Key Performance Indicators (KPIs):

- Total Customers: 3.9K
- Average Purchase Amount: $59.76
- Average Review Rating: 3.75

Dashboard Visualizations:

- Customers by Subscription Status
- Revenue by Category
- Sales by Category
- Revenue by Age Group
- Sales by Age Group

Interactive Filters:

- Subscription Status
- Gender
- Category
- Shipping Type
